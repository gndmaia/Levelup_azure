# Question Images

This folder contains images used in quiz questions.

## Required Images

The following images need to be copied from your SkillCertPro HTML file's `_files` folder:

1. `word-image-23.webp` - Clean Missing Data Module diagram
2. `word-image-24.webp` - Apples and bananas precision/recall diagram  
3. `word-image-232.webp` - Facial recognition tasks matching diagram
4. `word-image-233.webp` - Natural language processing output exhibit

## How to Add Images

1. Locate the `SkillCertPro_files` folder where you saved the HTML file
2. Copy the image files listed above to this folder
3. Refresh your browser - images will automatically display in questions
